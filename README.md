# 🚀 AI Code Editor

**AI Code Editor** is a modern web-based coding platform that helps developers write and interact with code using an AI-powered interface.


## ✨ Features

* AI-assisted coding interface
* Clean and responsive code editor UI
* Modern developer experience with Next.js
* Component-based architecture
* Role-based functionality (Developer & Product Manager)

---

## 👥 User Roles

### 🧑‍💻 Developer

Developers can use the editor to write, edit, and manage code efficiently in a modern web environment.

### 📋 Product Manager

Product Managers can review code workflows, track development progress, and manage project requirements through the interface.
